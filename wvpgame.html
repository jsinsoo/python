INTERACTIVE GAME 01

좌표 보물찾기

수학조작: 방향키 ← ↑ ↓ →
🎯 게임 목표파란 플레이어를 움직여 빨간 보물 5개를 획득하세요.
📘 핵심 개념좌표·거리·벡터
🎮 게임 방법방향키 ← ↑ ↓ →를 사용하여 실시간으로 참여합니다.
🏆 성공·판정 규칙보물과의 거리가 0.7보다 작아지면 점수 +1, 보물은 새 위치로 이동합니다.
Web VPython 3.2
scene.background = color.black
scene.range = 8

player = sphere(pos=vector(0,0,0), radius=0.35, color=color.cyan)
treasure = sphere(pos=vector(4,3,0), radius=0.4, color=color.red)
score = 0

def move(evt):
    global score
    step = 0.5
    if evt.key == 'left':  player.pos.x -= step
    if evt.key == 'right': player.pos.x += step
    if evt.key == 'up':    player.pos.y += step
    if evt.key == 'down':  player.pos.y -= step

    if mag(player.pos-treasure.pos) < 0.7:
        score += 1
        print("점수:", score)
        treasure.pos = vector(random()*12-6, random()*10-5, 0)

scene.bind('keydown', move)
print("방향키로 빨간 보물을 5개 찾으세요!")
🔎 코드·게임 상세 해설
키보드 이벤트가 발생할 때마다 player.pos의 x 또는 y 좌표를 바꿉니다. 두 점의 거리는 mag(player.pos-treasure.pos)로 계산합니다.
🚀 확장 탐구 미션
장애물 3개를 추가하고 장애물과 충돌하면 점수가 1점 감소하도록 수정해 보세요.

INTERACTIVE GAME 02

벡터 슈팅 게임

수학조작: 마우스 클릭
🎯 게임 목표화면을 클릭하여 그 방향으로 공을 발사하고 빨간 목표물을 맞히세요.
📘 핵심 개념벡터·방향·단위벡터
🎮 게임 방법마우스 클릭를 사용하여 실시간으로 참여합니다.
🏆 성공·판정 규칙클릭 위치와 발사점의 차이를 단위벡터로 만들고, 목표와의 거리가 0.6보다 작으면 명중입니다.
Web VPython 3.2
scene.background = color.black
scene.range = 8
gun = sphere(pos=vector(-6,0,0), radius=0.35, color=color.cyan)
target = sphere(pos=vector(5,2,0), radius=0.5, color=color.red)
bullet = None
v = vector(0,0,0)

def fire(evt):
    global bullet, v
    if bullet == None:
        bullet = sphere(pos=gun.pos, radius=0.15, color=color.yellow)
        direction = evt.pos - gun.pos
        v = 8*norm(direction)

scene.bind('click', fire)

while True:
    rate(100)
    if bullet != None:
        bullet.pos += v*0.02
        if mag(bullet.pos-target.pos) < 0.6:
            print("명중!")
            bullet.visible = False
            bullet = None
            target.pos = vector(random()*8, random()*8-4, 0)
        elif mag(bullet.pos) > 12:
            bullet.visible = False
            bullet = None
🔎 코드·게임 상세 해설
마우스로 클릭한 점 evt.pos와 발사점 gun.pos를 빼면 방향벡터가 됩니다. norm()은 길이가 1인 단위벡터를 만들고 8을 곱해 속도를 정합니다.
🚀 확장 탐구 미션
점수·제한시간·이동 목표물을 추가해 보세요.

함수 그래프 레이싱

📘 핵심 개념함수·미분 직관·그래프
🎮 게임 방법W/S 또는 ↑/↓를 사용하여 실시간으로 참여합니다.
🏆 성공·판정 규칙공과 함수값의 차이가 0.8보다 크면 체력이 감소합니다.
Web VPython 3.2
scene.background = color.black
scene.range = 7
path = curve(color=color.yellow, radius=0.03)
for i in range(-120,121):
    x = i/20
    y = 2*sin(x)
    path.append(pos=vector(x,y,0))

ball = sphere(pos=vector(-6,0,0), radius=0.25, color=color.cyan)
vy = 0
life = 100

def key(evt):
    global vy
    if evt.key == 'up' or evt.key == 'w': vy = 2
    if evt.key == 'down' or evt.key == 's': vy = -2

scene.bind('keydown', key)

while ball.pos.x < 6 and life > 0:
    rate(60)
    ball.pos.x += 0.04
    ball.pos.y += vy*0.02
    vy *= 0.93
    target_y = 2*sin(ball.pos.x)
    if abs(ball.pos.y-target_y) > 0.8:
        life -= 1

print("남은 체력:", life)

현재 x에서 함수값 2sin(x)를 계산하고 공의 y값과 비교합니다. 사용자는 위아래 조작으로 오차를 최소화합니다.
🚀 확장 탐구 미션
y=sin(2x), y=0.1x²-2 등 함수 종류를 바꾸어 난이도를 비교하세요.

scene.background = color.black

ball0 = vector(-7,-3,0)

while True:

scene.background = color.black
scene.range = 9
ground = box(pos=vector(0,-5,0), size=vector(16,0.4,3), color=color.gray(0.5))

fuel = 100

def key(evt):
    global v, fuel
    if evt.key == 'up' and fuel > 0:
        v.y += 0.35
        fuel -= 2
    if evt.key == 'left' and fuel > 0:

scene.background = color.black
scene.range = 8
source = sphere(pos=vector(-6,-3,0), radius=0.25, color=color.red)

ray = None

def place(evt):
    global ray
    m = evt.pos
    if ray != None: ray.visible = False
    ray = curve(color=color.red, radius=0.04)
    ray.append(pos=source.pos)
    ray.append(pos=m)

🏆 성공·판정 규칙적색 분자와 충돌하면 게임 종료입니다.
Web VPython 3.2
scene.background = color.black
scene.range = 7
player = sphere(pos=vector(0,0,0), radius=0.3, color=color.green)
enemies = []
for i in range(12):
    s = sphere(pos=vector(random()*10-5,random()*10-5,0),
               radius=0.25,color=color.red)
    s.v = vector(random()*4-2,random()*4-2,0)
    enemies.append(s)

def key(evt):
    if evt.key == 'w': player.pos.y += 0.5
    if evt.key == 's': player.pos.y -= 0.5
    if evt.key == 'a': player.pos.x -= 0.5
    if evt.key == 'd': player.pos.x += 0.5

scene.bind('keydown', key)
t = 0
while t < 20:
    rate(60); t += 1/60
    for s in enemies:
        s.pos += s.v/60
        if abs(s.pos.x)>6: s.v.x *= -1
        if abs(s.pos.y)>6: s.v.y *= -1
        if mag(s.pos-player.pos)<0.55:
            print("충돌! 생존시간:",round(t,1))
            t = 20
print("게임 종료")
🔎 코드·게임 상세 해설
적색 분자의 속도는 벡터로 표현되고 벽에서 해당 성분의 부호를 바꾸어 반사시킵니다.

🎮 게임 방법스페이스바를 사용하여 실시간으로 참여합니다.
🏆 성공·판정 규칙목표 농도 0.35±0.03에 가장 가까울수록 높은 점수를 얻습니다.
Web VPython 3.2
scene.background = color.white
g = graph(title="Reaction Challenge",xtitle="t",ytitle="A")
c = gcurve(color=color.blue)
A = 1.0
k = 0.35
t = 0
stop = False

def key(evt):
    global stop
    if evt.key == ' ':
        stop = True

scene.bind('keydown', key)

while not stop and A > 0.05:
    rate(30)
    A = A - k*A*0.05
    t += 0.05
    c.plot(t,A)

error = abs(A-0.35)
score = max(0,100-int(error*300))
print("정지 농도:",round(A,3),"점수:",score)

🚀 확장 탐구 미션
